# Release Notes: PDF Compressor v1.0.0

Welcome to the official 1.0.0 launch of **PDF Compressor**! 

After extensive development, testing, and security auditing, we are thrilled to release the stable V1.

## What's New in 1.0.0
- **100% Local Processing Engine**: Say goodbye to cloud uploads. Our custom-compiled qpdf WebAssembly core brings desktop-grade PDF compression directly into your browser.
- **Three Precision Modes**: 
  - *Balanced* (Default): The optimal mix of size reduction and visual clarity.
  - *Low*: Best for preserving image quality.
  - *High*: Best for maximizing space savings.
- **Smart Validation**: The extension automatically verifies the compressed file. If the compression isn't beneficial, your original file is safely kept.
- **Privacy-First Analytics**: We've implemented a strict, opt-in-only analytics system so you have full control over anonymous usage data sharing.
- **Modern Interface**: A clean, accessible, and responsive design that works beautifully as a popup. Full keyboard navigation and screen reader support included.
- **Zero Permissions**: Security is our priority. The extension requires exactly 0 permissions to run.

Enjoy fast, private, and secure PDF compression!
